观察要点
  1. λ ↑ → 条纹整体变宽、变红（x_k ∝ λ）。
  2. d ↓ → 条纹散开、k_max 变少；d ↑ 则级次挤向中央。
  3. d 与 a 各自独立：拖 a（d 不动）→ 包络宽窄变，d/a 跨过整数时缺级出现或消失；拖 d（a 不动）→ 缺级级次随 d/a 整体挪位。
  4. N ↑ → 条纹位置一位不变，只是变细变亮。
  5. 白光 → 零级仍是白的，±1 级才散成彩带。
  6. i ↑ → 整幅平移，而 Δsinθ 恒为 λ/d。

A改变条纹的位置与间距（谁在动 · 谁不动）
λ

波长变长 → 条纹整体变宽

d·sin θ = kλ　⇒　x_k ∝ λ

▾
各级位置由 d·sinθ = kλ 唯一决定：λ 增大，sinθ 按比例增大，整幅条纹同步散开，颜色由紫转红。
λ：550 nm → 700 nm　⇒　x₁ 由 55.08 mm 增至 70.17 mm（×1.27）
注意这是"整体变宽"而不是"变密"：所有级次一起外移，相邻间距也一起变大。
d

光栅常数变小 → 条纹散得更开

x_k ∝ 1/d　｜　k_max = ⌊d(1+sin i)/λ⌋

▾
d 是刻线的空间周期——周期越小，同样的波长差就能"磨"出更大的角度差，条纹散得越开；代价是最高级次 k_max 随之减少（谱线总数变少）。
d：10.0 μm → 5.0 μm（按钮演示里把 a 一并设为 2.50 μm，以维持 d/a = 2 的标准缺级；d 与 a 是两根独立滑块）
⇒ x₁ 由 55.08 mm 变为 110.67 mm（×2.01），k_max 由 18 降到 9
实验室里"想看得更开就换更高密度的光栅"，说的就是这一条。
B改变条纹的亮度与锐度（缝数的独家作用）
N

缝数 N：位置纹丝不动，只变细变亮

Δx = Lλ/d（与 N 无关）　δx ≈ Lλ/(N·d·cos³θ₁) ∝ 1/N

▾
把 N 从 20 拉到 200：±1 级始终钉在 55.08 mm，相邻间距 55.59 mm 一位数字都不变；变的只有谱线宽度——2.76 mm → 0.28 mm，细了整整十倍。
N = 2 　→ δx = 27.63 mm
N = 20 　→ δx = 2.76 mm
N = 200 → δx = 0.28 mm　（x₁ 恒为 55.08 mm）
原因：主极大位置由 d·sinθ = kλ 唯一决定，N 只决定 N 束光在中心方向上的相位叠加有多"锐"。这正是光栅比双缝分辨率高的全部秘密——分辨本领 R_分 = kN。
L

屏移远 → 条纹线性铺开

x_k ∝ L　（θ_k 不变）

▾
衍射角由 d 与 λ 决定，与屏放在哪里无关；屏越远，同样张角的条纹在屏上铺得越开，而各级的相对光强分布一点没变。
L：1.00 m → 1.20 m　⇒　x₁ 由 55.08 mm 变为 66.10 mm（×1.20），θ₁ 仍为 3.153°
所以"调屏距"是实验室里改变条纹尺度最方便的一根"杠杆"，但它不改变任何角信息。
C决定哪一级不存在——缺级
a:d

缺级：d/a 为整数时，那些级凭空消失

缺级条件 k = (d/a)·m　｜　包络零点 sinθ = mλ/a

▾
当 d/a 恰为整数，第 (d/a)·m 级主极大正好落在单缝衍射的第 m 级零点上——干涉要它亮，衍射偏不给光，这一级就凭空消失。当前 d/a = 2.00（标准光栅），所以 ±2、±4 … ±18 级全部为零。
d/a = 2.00（a = 5.0 μm）→ 缺 ±2, ±4, ±6, …, ±18
d/a = 2.50（a = 4.0 μm）→ 无缺级，全部级次现身
把 N 从 2 拉到 200 也救不回来——缺级是衍射包络的属性，与缝数完全无关。请在仿真中亲手试一次。
i

斜入射：整幅平移，Δsinθ 严格不变

d(sinθ − sin i) = kλ　⇒　θ_k = arcsin(sin i + kλ/d)

▾
光斜射入光栅时，零级不再沿光栅法线，而是沿入射方向偏出（θ₀ = i）：i = 5° 时零级跑到屏上 87.49 mm 处，整幅图样随之平移。
i = 0°　→ 零级 0.00 mm，相邻间距 55.59 mm
i = 5°　→ 零级 87.49 mm，相邻间距 57.49 mm
深入一步：严格守恒的是 Δsinθ ≡ λ/d = 0.055000（与 i 完全无关）；屏上 Δx 之所以从 55.59 mm 微涨到 57.49 mm，是 x = L·tanθ 这个换算式带来的非线性修正——那是 tan 的账，不是 sinθ 的账。读数条第 6 格可以现场验证这一点。
D白光与光谱——光栅与棱镜的根本区别
◎

白光下零级仍是白的，±1 级才散成彩带

k = 0 时 sinθ = 0，与 λ 无关

▾
打开白光开关，中央那条主极大纹丝不动、依然是白色——因为 k = 0 时 d·sinθ 恒等于 0，与波长毫无关系。只有 |k| ≥ 1 才有 sinθ = kλ/d，波长越长偏得越远，于是从紫到红散成一条彩带。
零级位移 = 0.00 mm（与 λ 无关）
一级展开：400 nm → 40.03 mm（紫）　700 nm → 70.17 mm（红）
这正是光栅与棱镜的根本区别：棱镜在零级附近色散最大、且只有"一级光谱"；光栅零级完全无色散，却能给出多级光谱。
⊂

第二级与第三级光谱会重叠

k₁λ₁ = k₂λ₂　⇒　λ_长/λ_短 > 1.5 即重叠

▾
光栅有"多级光谱"，代价是后一级的短波端会追上长波端：可见光 700/400 = 1.75 > 1.5，所以三级紫端（3×400 = 1200）与二级的 600 nm（2×600 = 1200）落在同一处——同一位置该算二级还是三级，光看位置分辨不出来。
三级 400 nm ≡ 二级 600 nm（同为 1200）
二级红端 1400 > 三级紫端 1200　⇒　必然重叠
这就是光栅光谱仪必须配滤光片（或前置棱镜预色散）来消除级次重叠的原因。
